# Pillar 7 — Efficient Workflow (WFL)

Conditional: this pillar is scored only when the skill dictates a multi-step workflow (not just rules or instructions). If the skill is purely declarative (style guides, linting rules, configuration), skip this pillar and exclude its weight from the overall score.

- **WFL-01 task-tracking** (judge): the workflow instructs the agent to register steps in the parent session's task list (TaskCreate/TaskUpdate or equivalent) so progress is visible and resumable. A workflow that runs silently with no task-list integration scores 0.
- **WFL-02 transcript-artifact** (judge): the workflow produces a persistent transcript, log, or summary artifact that enables later retrospection — a reviewer can understand what happened without re-running. An ephemeral workflow that leaves no trace scores 0.
- **WFL-03 graceful-degradation** (judge): the workflow handles non-happy-path situations without hard failure — missing files, partial input, unexpected tool output, user interruptions. A workflow that only succeeds on the exact happy path and errors on any deviation scores ≤1; one with explicit fallback/skip/retry logic scores 4.
- **WFL-04 step-autonomy** (judge): individual steps can succeed or fail independently without cascading the entire workflow into a terminal state. The workflow recovers, skips, or asks the user rather than aborting on the first non-fatal error.
- **WFL-05 checkpoint-resume** (judge): for long-running workflows, progress is checkpointed so work is not lost on interruption. Partial results are preserved and the workflow can resume from the last completed step rather than restarting from scratch.
- **WFL-06 output-per-step** (judge): each major step produces a visible intermediate output or status update — the user is not left watching silence for extended periods. Progress is communicated, not just the final result.
- **WFL-07 subartifacts** (judge): each significant step writes a named, persistent subartifact (file, JSON block, or task note) so the user can inspect individual outcomes, pinpoint failures, and resume from any completed step without re-running the whole workflow. A workflow that only emits a single final summary scores ≤1; one where every step leaves a traceable artifact scores 4.
