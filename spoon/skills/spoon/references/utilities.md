# Utilities

## Tokens

- `tips` — quick start. Reply with two lines:
  - Dosing: `sp 1m` → a 1-minute read, `sp 1s` → one sentence.
  - Verification: `sp ver` → the answer goes through verification.
- `sticky on` — keep the current arguments for the rest of the session.
- `sticky off` — stop keeping them.
